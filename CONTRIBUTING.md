# Contributing

Keep Afterglow quiet, cinematic and easy to run.

1. Fork the repository and follow the README's local setup.
2. Make a focused change on a new branch.
3. Run `npm test`, `npm run build` and `npm run test:e2e` with the local server running.
4. Open a pull request describing what changed. Include screenshots for visual changes.

Use your own API keys in `.env`. Never put keys, environment files, provider response dumps or account configuration in commits, screenshots or issues. The app must keep working when a rating or title logo is missing. Avoid permanent UI over the artwork.
